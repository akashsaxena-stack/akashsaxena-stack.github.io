Wells Fargo · 2026 · Azure Kubernetes Service
AKSArgo CDHelm RBACNetwork PoliciesWiz KSPM GitHub ActionsOIDCTrivy
Problem
No standardised Kubernetes deployment model — ad-hoc manifests, inconsistent RBAC, no security gates in delivery pipelines, manual cluster changes causing config drift.
Solution
Designed a GitOps-driven AKS platform using Argo CD and Helm with OIDC-authenticated pipelines embedding SonarCloud SAST, Trivy scanning, and Wiz KSPM. Enforced least-privilege RBAC, Network Policies, and Security Contexts across all workloads.

Zero manual cluster changes — all deployments PR-driven and auditable. Security gates blocking vulnerable images before they reach production. Full runtime posture visibility via Wiz.

Wiz CSPMAWSAzure n8nJiraSlack TerraformAzure PolicyPython
Problem

DevSecOps Pipeline Blueprint
GlobalLogic / Catalina Marketing · 2024–2026 · Azure DevOps + GitHub Actions
Azure DevOpsGitHub ActionsSonarCloud DASTtfsecWiz CNAPP ACRTerraformPolicy-as-Code
Problem
Security was entirely post-deployment — no SAST, no IaC scanning, no container hardening in pipelines. Vulnerable code and misconfigured infrastructure reaching production regularly.
Solution
Engineered a full shift-left DevSecOps pipeline integrating SonarCloud SAST, DAST, tfsec IaC scanning, Trivy container scanning, and Wiz CNAPP — with quality gates blocking non-compliant builds at every stage before merge and deploy.
Outcome
Security defects caught at commit rather than production. Configuration drift eliminated via automated Terraform + Policy-as-Code enforcement. Reusable pipeline template adopted across multiple teams.
